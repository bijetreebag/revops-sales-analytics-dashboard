# RevOps & Sales Analytics Dashboard

An interactive B2B revenue operations and sales pipeline dashboard built with Python and Streamlit.

## Features
* **Sales Pipeline Tracking:** Real-time visibility into deal stages and funnel velocity.
* **Revenue KPIs:** Tracks Monthly Recurring Revenue (MRR), average deal size, and win rates.
* **Dynamic Filters:** Filter revenue metrics by region, sales representative, and product lines.

## Tech Stack
* Python
* Streamlit
* Pandas
